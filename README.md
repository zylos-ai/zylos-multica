## Install

```bash
zylos add multica
```

Or manually:

```bash
cd ~/zylos/.claude/skills
git clone https://github.com/zylos-ai/zylos-multica.git multica
cd multica && npm install
```

## Configuration

Edit `~/zylos/components/multica/config.json`:

```json
{
  "enabled": true
}
```
